# Furuta 旋转倒立摆项目

整理日期：2026-11-23。目标为单级 Furuta：一个电机驱动水平横臂，末端摆杆被动摆动，通过能量起摆进入顶部反馈控制。直驱与双级 Furuta 保留为历史研究。

这是一份现有研发代码的整理快照。当前未完成真实执行器约束下的起摆到持续平衡闭环验收。历史对话中的成功结论只能对应当时模型与参数，不能外推到当前代码或实机。

## 从这里开始

1. 阅读 [项目现状与已知问题](Docs/STATUS.md)。
2. 阅读 [代码地图](Docs/CODE_MAP.md)，选择实验入口。
3. 按 [运行与构建](Docs/RUNNING.md) 在新设备配置环境。
4. 硬件接线与参数见 [硬件记录](Docs/HARDWARE.md)。
5. 开发过程见 [项目历史](Docs/HISTORY.md)，文件来源见 [来源说明](Docs/PROVENANCE.md)。
